# NOSDRA Oil Spill Analysis

## Overview
This project analyzes oil spill incidents reported by the National Oil Spill Detection and Response Agency (NOSDRA) to identify spill trends, affected states, recovery rates, and environmental impact.

## Objectives
- Analyze oil spill incidents across Nigeria.
- Identify the states with the highest number of spills.
- Measure oil recovery rates.
- Explore major spill causes.
- Build a Power BI dashboard for decision-makers.

## Tools
- SQL (BigQuery)
- Power BI
- Excel
